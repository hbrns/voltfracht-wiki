# Markdown in 5 Minuten

## Überschriften

```
# Überschrift H1
## Überschrift H2
### Überschrift H3
#### Überschrift H4
##### Überschrift H5
###### Überschrift H6
```

## Textformatierung

```
**Fett**
*Kursiv*
***Fett und kursiv***
~~Durchgestrichen~~
`Inline-Code`
```

## Links und Bilder

```
[Linktext](https://example.com)
[Link mit Titel](https://example.com "Hover-Titel")
![Alt-Text](image.jpg)
![Bild mit Titel](image.jpg "Bildtitel")
```

## Listen

```
Ungeordnet:

- Element 1
- Element 2
  - Verschachteltes Element

Geordnet:

1. Erstes Element
2. Zweites Element
3. Drittes Element
```

## Blockzitate

```
> Dies ist ein Blockzitat
> Mehrere Zeilen
>> Verschachteltes Zitat
```

## Codeblöcke

````
```javascript
function hello() {
  console.log("Hallo Welt!");
}
```
````

## Tabellen

```
| Spalte 1 | Spalte 2 | Spalte 3 |
|----------|----------|----------|
| Zeile 1   | Daten    | Daten    |
| Zeile 2   | Daten    | Daten    |
```

## Horizontale Linie

```
---
oder
***
oder
___
```

## Aufgabenlisten

```
- [x] Erledigte Aufgabe
- [ ] Unerledigte Aufgabe
- [ ] Weitere Aufgabe
```

## Sonderzeichen maskieren

```
Verwende Backslash zum Maskieren: \* \_ \# \`
```

## Zeilenumbrüche

```
Beende eine Zeile mit zwei Leerzeichen  
um einen Zeilenumbruch zu erzeugen.

Oder verwende eine Leerzeile für einen neuen Absatz.
```
